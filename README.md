# hitchstead.com

Static site for Hitchstead (iPhone calendar for rotation work). Plain HTML/CSS, served by GitHub Pages with the custom domain in `CNAME` (DNS at Cloudflare).

- `index.html`: landing page. The example year is generated: edit `tools/year.py`, then run `python3 -I tools/year.py`.
- `support/`, `privacy/`: moved from interactivemedia91-arch.github.io/hitchstead/privacy.html (same text).
- `assets/`: stylesheet, icons, app screens (from the app's App Store captures), Apple's official App Store badge.
- Product and design context: `PRODUCT.md`, `DESIGN.md`, `.impeccable/`.
